# Changelog

All notable changes are documented here. The project follows semantic versioning once the public contract stabilizes.

## [0.1.0] - 2026-07-28

### Added

- strict `media-economics-event.v1` call and artifact receipt validation
- `media-economics-policy.v1` operation budgets and allowlists
- exact, estimated, unknown, and not-applicable evidence separation
- cache-evidence, retry lineage, duplicate-work, hidden-call, and artifact-link checks
- quality-gated exact cost per accepted artifact
- deterministic JSON and Markdown audit bundles with SHA-256 manifests
- baseline/candidate comparison with a quality-preservation rule
- synthetic paired and adversarial examples
- no-network CLI, tests, security scan, and CI

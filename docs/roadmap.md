# Roadmap

The roadmap is ordered by evidence value, not feature count.

## v0.1 — Public kernel

- strict call, artifact, and policy contracts
- evidence coverage and waste diagnostics
- deterministic audit and comparison bundles
- synthetic paired and adversarial fixtures
- cross-version CI and public-boundary scan

## v0.2 — Signed receipt boundary

- pluggable verified-host receipt signature interface
- detached manifest signatures
- bounded input-size and event-count controls
- JSON Schema exports generated from the runtime contract

## v0.3 — Adapter SDK

- documented adapter protocol
- reference adapters using recorded synthetic provider payloads
- conformance test suite for exact usage and cache semantics
- currency-conversion receipt extension without embedded exchange rates

## v0.4 — Experiment discipline

- paired workload manifest
- gate-version and dataset-fingerprint checks
- confidence intervals for repeated controlled runs
- overlapping-waste attribution model

## Explicitly deferred

- hosted dashboard
- production prompt storage
- provider price tables
- model routing recommendations without measured quality
- automatic publication or upload actions

A feature enters a release only with an adversarial test and a clear statement of what new claim it can prove.
